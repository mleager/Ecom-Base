# Chat Handoff Prompt

We are reaching the context limit. Generate a concise Markdown handoff document for a fresh AI session. Include:

1. Project State: High-level architecture summary and tech stack.

2. Progress Log: What features we just completed and what bugs we fixed.

3. Current State: The precise files we are actively editing right now.

4. Next Steps: A clear, prioritized backlog of what to do next.

5. Gotchas: Any hidden constraints, API quirks, or architectural patterns we explicitly agreed to stick to.
