## Limits and Milestone 14 handoff

The acceptance target is the local Windows/pinned Chromium baseline. Sampled opaque contrast, default-scale widths, forced autofill/forced colors and root-font scaling checks do not certify all pixels, actual browser zoom, password managers, assistive technology, other browser engines or physical devices. Those limits remain explicit. Dated backend race/crash and controlled-mailbox results keep their original scope; this visual increment adds no fresh claim for them.

M14 owns production SPA/API serving and direct-route fallback, HTTPS/session/proof and browser-storage behavior, application image/Compose deployment, explicit migrations/readiness/recovery, reproducible release evidence and the final immutable healthy tag for Projects 2–6. Preserve schema/readiness **11**, fixture version **1**, OpenAPI **1.5.0** with **38 business + 3 operational** operations, the existing checkout/session/stock guarantees, local tool pins and private configuration boundaries. Track the existing bundle warning and clock mitigation during release verification. No packaging, publishing or tagging occurs in M12.
