## Cart data and arithmetic readiness

The backend cart contract stays unchanged. `TestCartPresentationReadiness` verifies that existing product reads supply bounded prices and optional image fallback input, retirement leaves a cart line present, public lookup then returns 404, and removal by cart-item ID still succeeds. A valid cart can contain quantity 10,000 with unit price 1,000,000,000,000 cents; its estimate must be rejected before unsafe multiplication rather than represented as zero or a complete total.

M9 acceptance verifies one enrichment generation with 100 distinct IDs, at most four requests in flight, one attempt per ID, a ten-second overall deadline, abort/ignore on navigation/newer load/user switch, and explicit retry for failed/unstarted reads. A 404 is unavailable; a network/500 error is a distinct display failure. Neither prevents removal/clear. These browser scheduling/UI guarantees are not implemented by the backend readiness test.

| Input | Required estimate behavior |
|---|---|
| 1,234 cents × 2; all other lines priced within bounds | 2,468 cents, clearly estimated. |
| Zero price, valid quantity | Legitimate zero-priced line; distinguish from a missing price. |
| 1,000,000,000,000 cents × 1 | At the permitted line/order bound. |
| Same price × 2, or × 10,000 | Out-of-range estimate; reject before multiplication. |
| Two lines of 600,000,000,000 cents each | Out-of-range sum; reject before addition. |
| Any missing/retired/failed enrichment | No complete subtotal; do not price an unknown line as zero or present a partial sum as complete. |

Use integer cents. Before multiplying a nonzero unit price, require quantity no greater than `floor(maximum / unit_price)`; before adding, require line total no greater than `maximum - subtotal`, with maximum 1,000,000,000,000. Validate finite safe integer inputs and handle zero price separately. The backend remains authoritative at checkout. These boundaries are verified by the M9 money/enrichment suites; the browser remains a presentation layer, not a second pricing service.
