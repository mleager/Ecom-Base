# Shared presentation primitives

Button and Input are project-owned adaptations of the official shadcn `new-york-v4` registry, reviewed through its MCP server and installed CLI **4.23.0** on 2026-11-02. [Upstream registry](https://ui.shadcn.com/r/styles/new-york-v4/button.json), [Input](https://ui.shadcn.com/r/styles/new-york-v4/input.json) and the [retained MIT notice](SHADCN_LICENSE.md) identify their origin. Review future registry diffs before updating; do not overwrite project behavior with generated defaults.

- Import components through `@/shared/ui/primitives/…`; `@/shared/ui/utils` owns class merging. Vite/Vitest and TypeScript resolve `@` to `src`.
- Tailwind **4.3.3** uses `tw:` utilities and prefixed theme tokens. `src/tailwind.css` maps the existing semantic palette; it deliberately omits Preflight and scans application source rather than fixtures or browser tests. Legacy CSS/Modules coexist; migrated controls opt out of legacy element styling through `data-slot`. Shared focus, forced-color and autofill rules remain in `styles.css`.
- Keep 44px minimum targets, wrapping text, opaque semantic colors and full-opacity disabled controls. No animation dependency is installed. Button defaults to `type="button"`; form submission requires explicit `type="submit"`. Disabled actions use native buttons; an `asChild` link must remain navigation, not a disabled action. Give icon buttons accessible names.
- Button uses the individual `@radix-ui/react-slot` primitive, avoiding the full Radix collection; `class-variance-authority` owns variants and `cn` merges classes. Input forwards native props/ref; Field remains responsible for label, required indication, hint and error associations. Neither component owns requests, validation, private state or mutation retries.
- Task 7 adapts Card, Badge, Dialog and Sheet, Native Select and Textarea for production. Dialog and Sheet share the already pinned Radix Dialog runtime for modal focus, Escape and return to the trigger. The catalog and administrator adapters share a search InputGroup while retaining their own route/query behavior. Alert and empty/loading states preserve their live-region semantics.
- Keep feature-specific presentation in its owning increment. Task 11 runs the full revised-browser gate.

Use the **installed** CLI from `frontend/`: `./node_modules/.bin/shadcn.cmd add … --dry-run` on Windows (the local `shadcn` executable on other shells). Inspect generated config/source/dependency changes and rerun type/build/tests; TypeScript 7 uses `paths` without removed `baseUrl`. `components.json` selects the official registry style, aliases, CSS entry and prefix; the icon-library setting installs no icon package. The project MCP configuration launches this same local CLI with the frontend working directory; a running client reads configuration changes on its next server startup.
